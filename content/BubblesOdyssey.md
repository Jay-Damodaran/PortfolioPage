For an embedded systems game competition, I worked with a partner to build a platformer game in 2 weeks on an MSPM0 MCU, featuring a squirrel named Bubbles collecting acorns for winter while fighting enemies. 

- Designed a C-based embedded video game with SPI-driven LCD graphics
- Implemented edge-triggered GPIO interrupts for responsive user input and hardware timer ISRs for precise movement, animation, and power-up duration
- Integrated event-driven audio using the MSPM0’s 12-bit DAC and a speaker 
- Designed game logic for animated character control, enemy behavior, collision detection, and projectile dynamics in real-time
